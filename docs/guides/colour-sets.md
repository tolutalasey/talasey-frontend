# Colour sets

A colour set is a list of colours you can give to products where the customer picks a colour that doesn't change the SKU or the price, such as powder-coated screens (page type 1B) or made-to-measure planters (page type 2).

You need the **catalogue** or **owner** role. The owner can give it to you under **Staff** in the admin.

## Make a colour set

1. In the admin, open **Colour sets**.
2. Under **Add a colour set**, give it a name, such as Standard powder coat.
3. List the colours one per line: the name as customers see it, a comma, then the screen colour as a hex value, such as `Anthracite grey (RAL 7016), #383E42`.
4. Press **Add colour set**.

The order you list colours in is the order customers see them. Hex values are only for the swatch on screen; the photo shows the true colour.

## Give a product a colour set

1. Open the product in the admin and scroll to **How it sells**.
2. Set the page type to **1B** (or **2** for made to measure).
3. Choose the colour set.
4. Under **Show the colours when … is …**, choose the option and type the value that use colours, such as **Finish** and **Powder coated**. Leave them as **Always** and empty if every option comes in these colours.
5. Leave **Shoppers must choose a colour** ticked unless the colour is optional.
6. Press **Save**.

## Undo a change

Open **Change log**. Every change is listed with who made it. **Put back as before** puts things back as they were before that change. That is logged too, so it can be undone the same way.

You can't delete a colour set that products still use. Move them to another set first.
