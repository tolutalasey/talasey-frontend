# Using the content editor

Open `/content` on the site and sign in. On the left is every kind of content: the homepage, brand, project and range pages, guides, questions and answers, inspiration photos, navigation, site settings, redirects, email wording, and approved legal and finance wording.

## Drafts and publishing

- **Save draft** keeps your work. The site keeps showing the published version until it is published again.
- Contributors save drafts; an editor publishes them. Only the owner publishes legal and finance wording.
- Before publishing, anything missing or too long is listed at the top, such as a search title that isn't 30 to 60 characters. Fix the list and publish.
- **Preview the draft** shows guides and pages as the site will, before anyone else sees them.
- **Take off the site** unpublishes but keeps the draft. **History** shows every change and can put an earlier version back.

## Product extras

**Product extras** add to a product's page what isn't in the product data: the "complete the job" list, downloads, key features and the guarantee.

1. Start a draft and name it with the end of the product's web address, for example `silver-grey-porcelain-paving` for `/products/silver-grey-porcelain-paving/`.
2. Under **Complete the job**, add each product that goes with it (again by the end of its web address) and why it's needed, such as "Fills the joints between the slabs". Customers see each one with its own tick box, never ticked for them, and only when it can be bought online.
3. Under **Documents**, add spec sheets and fitting guides with a link starting `https://` or `/`.
4. **Save and publish.** The product page shows it within seconds.

## Releases: several changes at once, now or later

Use a release when changes must go live together, for example a sale's landing page, banner and FAQs, or when something should go live at a set time, such as 9am on Monday. Editors and the owner can do this.

1. Go to **Releases**, type a name such as "Spring sale" and click **Start a release**.
2. Open each draft, make your changes, choose the release and click **Save and add to release**. The site doesn't change yet.
3. Back in **Releases**, either pick a date and time (UK time) and click **Schedule**, or click **Publish everything now**.

Everything in a release goes live at the same moment. If one draft still has something to fix, nothing in the release is published, and the release shows what to fix. Changing a scheduled release (adding or taking out a draft) unschedules it, so check it and schedule it again.

## Filling in fields

- Paragraphs: leave a blank line between them.
- Lists such as steps or key points: one per line.
- Rows such as questions and answers: there is always one empty row at the bottom for a new one. To remove a row, empty its fields and save.
- Photos: choose a file and describe what it shows for people who can't see it.
- Web addresses: lower-case words joined by hyphens, like `how-to-lay-a-porcelain-patio`. No dates or codes.

## Built-in copy

Until something is published here, the site shows its own placeholder copy for that page, marked so search engines ignore it. Publishing an entry with the same web address replaces it.
